# Как изменить цены на сайте

Основные цены находятся в файле `index.html`. Откройте его в редакторе кода или в обычном текстовом редакторе.

## 1. Цены в таблице

Найдите блок с заголовком:

```html
<h2 id="prices-title">Ориентиры по стоимости</h2>
```

Ниже находится таблица цен. Меняйте значения внутри строк:

```html
<td data-label="Цена">от 350 ₽/м²</td>
<td data-label="Цена">от 400 ₽/м²</td>
<td data-label="Цена">от 450 ₽/м²</td>
<td data-label="Цена">от 900 ₽/п.м.</td>
<td data-label="Цена">от 300 ₽/шт.</td>
<td data-label="Цена">от 350 ₽/шт.</td>
```

Например, если матовый потолок стал стоить от 500 ₽/м², замените:

```html
от 350 ₽/м²
```

на:

```html
от 500 ₽/м²
```

## 2. Цены в калькуляторе

В этом же файле `index.html` найдите:

```html
<select id="ceiling-type" required>
```

Там указаны цены, которые использует калькулятор:

```html
<option value="350">Матовый — 350 ₽/м²</option>
<option value="400">Глянцевый — 400 ₽/м²</option>
<option value="450">Сатиновый — 450 ₽/м²</option>
```

Важно менять и число в `value`, и видимый текст.

Пример:

```html
<option value="500">Матовый — 500 ₽/м²</option>
```

## 3. Цена установки светильника в калькуляторе

Если изменилась цена установки светильника, откройте файл `script.js`.

Найдите строку:

```js
var total = area * price + lights * 350;
```

Число `350` здесь означает стоимость одного светильника.

Например, если установка светильника стала 450 ₽, замените строку на:

```js
var total = area * price + lights * 450;
```

## 4. Стартовая сумма в калькуляторе

В `index.html` есть начальный текст результата:

```html
<output class="calc-result" id="calc-result">Ориентировочная стоимость: 7 700 ₽</output>
```

Это только стартовая подпись до пересчета. Можно заменить на новую примерную сумму или оставить как есть: после загрузки страницы калькулятор сам пересчитает значение.

## 5. Минимальная цена для поисковиков

Если меняется минимальная цена `от 350 ₽/м²`, также обновите ее в верхней части `index.html`:

```html
<title>Натяжные потолки в Тамбове от 350 ₽/м² — Виктор-Профи</title>
<meta property="og:title" content="Натяжные потолки в Тамбове от 350 ₽/м² — Виктор-Профи">
"priceRange": "от 350 ₽/м²",
```

Например, если минимальная цена стала 500 ₽/м², замените `350` на `500` в этих местах.

## 6. Быстрый способ проверить все цены

В редакторе используйте поиск по файлам:

```text
350
400
450
900
300
```

Так проще найти все старые цены и не пропустить нужное место.

## 7. Что не нужно менять

Файл `styles.css` отвечает за внешний вид сайта. Цены там менять не нужно.

Папка `img` содержит изображения. Для изменения цен она не нужна.

## 8. Проверка после изменения

После сохранения файлов откройте сайт и проверьте:

- блок `Цены`;
- калькулятор стоимости;
- заголовок страницы, если менялась минимальная цена;
- что кнопки перехода, телефон и почта работают как раньше.

Если сайт публикуется через Netlify, после правок загрузите обновленную папку сайта или новый zip-архив в Netlify.

# Если форму заявки решат вернуть позже

Сейчас форма заявки убрана с сайта. На странице оставлены прямые способы связи: телефон, email и пометка про MAX по номеру телефона.

Если позже нужно вернуть отправку заявок на почту, важно понимать: статический HTML-сайт сам по себе письма не отправляет. Нужен отдельный сервис обработки формы, например Netlify Forms, Formspree, серверный скрипт на хостинге или CRM-виджет.

Если использовать Netlify Forms, почта получателя заявок указывается не в коде сайта, а в панели Netlify:

```text
Site configuration / Configuration
Notifications
Form submission notifications
Add notification
Email notification
```

Для теста получателя тоже лучше менять в Netlify: временно указать свою почту, отправить тестовую заявку на опубликованном сайте, проверить Forms / Verified submissions и входящие письма, затем вернуть почту Виктора.

Локально, через обычное открытие `index.html` или локальный сервер, отправку Netlify Forms полноценно проверить нельзя. Надежная проверка делается только на опубликованном сайте Netlify.

# Где в коде указана почта Виктора

В коде сайта почта `Victor_p_@mail.ru` используется как контактная почта на странице.

Чтобы заменить контактную почту на сайте, используйте поиск по файлам:

```text
Victor_p_@mail.ru
```

Обычно заменить нужно в:

```text
index.html
```

В `index.html` почта есть в блоке контактов:

```html
<a class="contact-email" href="mailto:Victor_p_@mail.ru">Victor_p_@mail.ru</a>
<button class="copy-contact" type="button" data-copy="Victor_p_@mail.ru" aria-label="Скопировать почту">Скопировать</button>
```

Если меняете адрес, замените его в трех местах:

```html
href="mailto:НОВАЯ_ПОЧТА"
НОВАЯ_ПОЧТА
data-copy="НОВАЯ_ПОЧТА"
```

В `script.js` почта сейчас не используется, потому что форма заявки убрана.
