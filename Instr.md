## 2. Важная проверка по текущему сайту

По опубликованной ссылке Netlify сейчас видна не самая последняя версия сайта.

На опубликованной странице всё еще есть признаки старой версии:

* пункт меню «Отзывы»;
* блок «Отзывы клиентов»;
* фраза в форме: «Данные никуда не отправляются, пока на сайте не подключен backend»;
* кнопка WhatsApp;
* блок «Примеры будущего портфолио» вместо реальных фото;
* в тексте этапов есть упоминание WhatsApp.

Это значит, что последние правки из Codex, скорее всего, еще не загружены на Netlify или загружен не тот ZIP.

### Что нужно сделать первым делом

1. Открыть папку проекта:

```text
C:\Users\79202\Documents\Codex\2026-05-27\7-920-481-17-77-email
```

2. Проверить, что там лежит последняя версия:

* меню «Клиентам», а не «Отзывы»;
* реальные фото в папке `img`;
* нет кнопки WhatsApp;
* есть новый логотип, если уже добавлен;
* в форме честный текст про тестовый режим.

3. Заархивировать именно содержимое папки, а не саму папку.

Правильно внутри ZIP:

```text
index.html
styles.css
script.js
robots.txt
sitemap.xml
img/
```

Неправильно:

```text
7-920-481-17-77-email/index.html
```

4. Загрузить новый ZIP в Netlify:

```text
Netlify → viktorprofi → Deploys → Manual deploys → перетащить ZIP
```

5. После загрузки открыть сайт в режиме инкогнито или обновить через `Ctrl + F5`.

## 3. Что исправить на сайте перед полноценным запуском

### 3.1. Обновить опубликованную версию

Сейчас главное — добиться, чтобы на Netlify была именно последняя версия сайта.

После обновления на опубликованном сайте должно быть:

* меню: «Услуги», «Цены», «Работы», «Этапы», «Клиентам», «Контакты»;
* реальные фото работ;
* без WhatsApp-кнопки;
* контакты: телефон, email, MAX по номеру;
* форма без обещания автоматической отправки;
* блок «Что важно для клиентов», а не фейковые отзывы;
* новый логотип.

### 3.2. Заменить временный логотип на финальный

Когда финальный логотип будет готов, его лучше сохранить в папку:

```text
img/logo-viktor-profi.png
```

Для первого экрана можно использовать крупное изображение:

```text
img/hero-logo.png
```

Для маленького логотипа в шапке лучше сделать отдельную легкую версию или оставить текстовый логотип.

### 3.3. Проверить фото

Фотографии лучше переименовать без русских букв и пробелов:

```text
work-1.jpg
work-2.jpg
work-3.jpg
work-4.jpg
```

Так сайт стабильнее работает на разных хостингах.

### 3.4. Убрать всё, что пока не работает

До подключения заявок не нужно писать, что форма реально отправляет данные.

Правильный текст:

```text
Сейчас форма работает в тестовом режиме. Для связи позвоните по номеру +7 920 481-17-77 или напишите на почту Victor_p_@mail.ru.
```

Нужен не VPS, не сервер, не Docker, а простой хостинг с файловым менеджером.

## 6. Как подключить Яндекс.Метрику

### 6.1. Что такое Яндекс.Метрика

Яндекс.Метрика — это счетчик статистики. Он показывает, что делают посетители на сайте.

Метрика отвечает на вопросы:

* сколько людей зашло на сайт;
* откуда они пришли;
* с телефона или компьютера;
* какие кнопки нажимали;
* сколько людей нажали на телефон;
* сколько людей дошли до формы;
* какие блоки смотрят;
* где люди уходят с сайта;
* работает ли реклама.

Без Метрики реклама и SEO будут почти вслепую.

### 6.2. Где это делается

Метрика настраивается не на хостинге, а в сервисе Яндекса:

```text
metrika.yandex.ru
```

На хостинг или в Netlify потом просто загружается сайт, в который вставлен код счетчика.

То есть порядок такой:

```text
Яндекс.Метрика → создать счетчик → получить код → вставить код в index.html → загрузить сайт на Netlify/хостинг
```

### 6.3. Можно ли подключить Метрику сейчас

Да, можно подключить уже сейчас к адресу:

```text
viktorprofi.netlify.app
```

Но лучше понимать: когда купим домен `viktor-profi.ru`, в настройках счетчика нужно будет добавить новый адрес сайта.

Можно сделать так:

* сейчас добавить основной адрес `viktorprofi.netlify.app`;
* потом добавить дополнительный адрес `viktor-profi.ru`;
* после полного переезда оставить основным новый домен.

### 6.4. Как создать счетчик пошагово

1. Зайти на сайт:

```text
metrika.yandex.ru
```

2. Войти через Яндекс ID.

Лучше использовать отдельный рабочий аккаунт, например:

```text
viktorprofi@yandex.ru
```

Не обязательно, но так удобнее в будущем.

3. Нажать «Добавить счетчик».

4. Заполнить поля:

```text
Имя счетчика: Виктор-Профи
Адрес сайта: viktorprofi.netlify.app
Часовой пояс: Москва
Валюта: RUB
```

Важно: в поле адреса сайта обычно не нужно писать `https://`, достаточно домена.

5. Включить:

```text
Вебвизор, карта скроллинга, аналитика форм
```

Это полезно, потому что можно будет увидеть, как люди реально двигаются по сайту.

6. Принять условия.

7. Нажать «Создать счетчик».

8. Яндекс выдаст HTML-код.

9. Скопировать код.

### 6.5. Куда вставлять код Метрики

Код нужно вставить в файл:

```text
index.html
```

Лучшее место — перед закрывающим тегом:

```html
</head>
```

У нас в коде уже должен быть комментарий:

```html
<!-- Здесь будет код Яндекс.Метрики -->
```

Можно вставить код прямо вместо этого комментария.

После вставки:

1. Сохранить `index.html`.
2. Загрузить обновленный сайт на Netlify.
3. Открыть сайт.
4. Вернуться в Метрику.
5. Проверить, что счетчик найден.

### 6.6. Что такое Вебвизор

Вебвизор — это запись поведения посетителей. Он показывает примерно так:

```text
человек зашел → прокрутил страницу → нажал кнопку → ушел
```

Это помогает понять:

* видят ли люди кнопку «Позвонить»;
* доходят ли до цен;
* смотрят ли фото;
* мешает ли что-то на мобильной версии.

### 6.7. Что такое цели в Метрике

Цель — это полезное действие посетителя.

Для сайта «Виктор-Профи» цели должны быть такими:

```text
click_phone — клик по телефону
click_email — клик по email
click_calculator — клик по расчету стоимости
form_submit_test — отправка тестовой формы
view_contacts — переход к контактам
```

Метрика будет считать, сколько людей сделали эти действия.

### 6.8. Как создать цели без сложного кода

В Метрике есть простые цели:

* клик по номеру телефона;
* клик по email;
* клик по кнопке;
* отправка формы.

Для начала можно создать цели прямо в интерфейсе Метрики:

```text
Метрика → нужный счетчик → Настройки → Цели → Добавить цель
```

Рекомендуемые цели:

#### Цель 1. Клик по телефону

Тип:

```text
Клик по номеру телефона
```

Название:

```text
Клик по телефону
```

#### Цель 2. Клик по email

Тип:

```text
Клик на email
```

Название:

```text
Клик по email
```

#### Цель 3. Отправка формы

Тип:

```text
Отправка формы
```

Название:

```text
Отправка формы
```

#### Цель 4. Клик по кнопке «Рассчитать стоимость»

Тип:

```text
Клик по кнопке
```

Название:

```text
Клик Рассчитать стоимость
```

### 6.9. Когда цели лучше делать через код

Если автоматические цели работают неточно, можно попросить Codex добавить события в `script.js`.

Пример логики:

```javascript
ym(НОМЕР_СЧЕТЧИКА, 'reachGoal', 'click_phone');
```

Но на старте можно попробовать встроенные цели Метрики, они проще.

## 7. Как подключить Яндекс.Вебмастер

### 7.1. Что такое Яндекс.Вебмастер

Яндекс.Вебмастер — это сервис для владельца сайта.

Он показывает:

* видит ли Яндекс сайт;
* какие страницы попали в поиск;
* есть ли ошибки;
* работает ли `robots.txt`;
* работает ли `sitemap.xml`;
* по каким запросам сайт показывается;
* какие страницы исключены из поиска.

Метрика показывает поведение людей. Вебмастер показывает, как сайт видит поисковик.

### 7.2. Когда подключать

Лучше подключать после покупки домена:

```text
https://viktor-profi.ru/
```

К Netlify тоже можно подключить, но для SEO лучше продвигать нормальный домен.

### 7.3. Как добавить сайт

1. Зайти:

```text
webmaster.yandex.ru
```

2. Нажать «Добавить сайт».

3. Ввести адрес:

```text
https://viktor-profi.ru/
```

4. Подтвердить права.

Самый простой способ — HTML-файл.

Яндекс даст файл примерно такого вида:

```text
yandex_1234567890abcdef.html
```

Нужно:

1. Скачать этот файл.
2. Положить его рядом с `index.html`.
3. Загрузить сайт на хостинг.
4. Нажать «Проверить» в Вебмастере.

### 7.4. Как добавить sitemap.xml

После подтверждения сайта:

```text
Яндекс.Вебмастер → Индексирование → Файлы Sitemap
```

Добавить:

```text
https://viktor-profi.ru/sitemap.xml
```

Если сайт пока на Netlify:

```text
https://viktorprofi.netlify.app/sitemap.xml
```

Но лучше делать это уже на основном домене.

## 9. Как потом подключить Яндекс.Директ

### 9.1. Что такое Яндекс.Директ

Яндекс.Директ — это платная реклама в Яндексе.

Например, человек пишет:

```text
натяжные потолки Тамбов
```

И видит рекламное объявление сайта.

### 9.2. Когда запускать рекламу

Не стоит запускать рекламу до базовой подготовки.

Сначала нужно:

* сайт открывается без VPN;
* есть нормальный домен;
* подключена Метрика;
* настроены цели;
* есть реальные фото;
* кнопки связи работают;
* понятно, куда приходит заявка.

### 9.3. Почему Метрика нужна до рекламы

Директу нужны цели из Метрики.

Например:

```text
Клик по телефону
Отправка формы
Клик по email
```

Тогда будет видно не просто «100 человек зашли», а:

```text
100 человек зашли → 8 нажали телефон → 2 оставили заявку
```

### 9.4. Какие запросы брать для рекламы

Основные:


## 10. SEO: как попадать выше в поиске

### 10.1. Что важно понимать

SEO — это не кнопка «попасть в топ». Это постепенная работа.

Для локального сайта по Тамбову шансы хорошие, но нужно:

* нормальный домен;
* стабильный хостинг;
* уникальные тексты;
* реальные фото;
* карточка в Яндекс.Бизнес;
* отзывы;
* отдельные страницы под услуги;
* регулярные обновления.

### 10.2. Главные запросы

```text
натяжные потолки Тамбов
натяжные потолки в Тамбове
натяжные потолки Тамбов цена
установка натяжных потолков Тамбов
монтаж натяжных потолков Тамбов
натяжные потолки Тамбовская область
```

### 10.3. Какие страницы добавить позже

Сейчас сайт — одностраничник. Для SEO лучше постепенно сделать отдельные страницы:

```text
/svetovye-linii.html — Потолки со световыми линиями в Тамбове
/matovye.html — Матовые натяжные потолки в Тамбове
/glyancevye.html — Глянцевые потолки в Тамбове
/satinovye.html — Сатиновые потолки в Тамбове
/kuhnya.html — Натяжные потолки на кухню в Тамбове
/vannaya.html — Натяжные потолки в ванную в Тамбове
/ceny.html — Цены на натяжные потолки в Тамбове
```

### 10.4. Что должно быть на каждой SEO-странице

* заголовок с услугой и городом;
* 1000–2500 знаков нормального текста;
* реальные фото;
* ориентиры по цене;
* FAQ;
* кнопка звонка;
* ссылка на главную;
* уникальный title и description.

### 10.5. Фото тоже помогают SEO

У фото должны быть нормальные имена:

```text
svetovye-linii-tambov-1.jpg
matovyj-potolok-tambov-1.jpg
potolok-vannaya-tambov-1.jpg
```

И alt-текст:

```text
Световые линии на натяжном потолке в Тамбове
```

## 11. Что делать с заявками

Сейчас форма работает в тестовом режиме.

### Вариант 1. Только телефон и email

Самый простой вариант для старта.

На сайте оставить:

* кнопку «Позвонить»;
* email;
* текст «Можно написать в MAX по номеру».

На российском хостинге можно сделать:

```text
форма → send.php → письмо на Victor_p_@mail.ru
```

На Netlify PHP не работает.

### Вариант 3. Telegram-уведомления

Можно сделать:

```text

```

Это удобно, потому что заявка приходит сразу.

## 12. План дальнейших действий

### Этап 1. Привести текущий сайт в порядок

1. Обновить Netlify последней версией.
2. Проверить, что исчезли старые блоки: «Отзывы», WhatsApp, старый текст формы.
3. Добавить финальный логотип.

## 15. Самый короткий план простыми словами

```text
1. Обновить Netlify последней версией сайта.
2. Доделать логотип.
3. Купить домен viktor-profi.ru.
4. Перенести сайт на российский хостинг.
5. Подключить Яндекс.Метрику.
6. Настроить цели: телефон, email, форма, расчет стоимости.
7. Добавить сайт в Яндекс.Вебмастер.
8. Создать карточку в Яндекс.Бизнесе.
9. Добавить больше фото и реальные отзывы.
10. Постепенно делать SEO-страницы под отдельные услуги.
```

Главная мысль: сначала нужно не «продвигать», а сделать сайт измеряемым. Для этого нужна Метрика и цели. Только потом реклама и SEO будут понятными: будет видно, откуда приходят люди и какие действия они совершают.
